# Data Professional Survey Dashboard

An interactive Power BI dashboard analyzing career data, salary benchmarks, and workplace satisfaction metrics from 630 data professionals globally. This project highlights end-to-end data preparation (ETL) and interactive dashboard design.

## Key Insights Captured
*   **Salary Benchmarks:** Data Scientists and Architects command the highest average salaries.
*   **Tech Preferences:** Python is overwhelmingly favored as the top programming language.
*   **Industry Barriers:** Over 40% of respondents feel breaking into the data field is "Neither easy nor difficult," followed closely by "Difficult."
*   **Work-Life Balance:** Professionals report a moderate satisfaction score of 5.74/10.

## Technical Stack & Skills
*   **Tool:** Power BI Desktop
*   **Core Skills:** Data Cleansing, ETL Pipeline, Data Modeling, Information Design, Data Storytelling

## Data Transformation (Power Query)
The raw survey data required comprehensive restructuring before visualization. Key ETL steps executed include:
*   **Column Splitting:** Separated multi-value text responses into distinct fields for clean aggregation.
*   **Data Type Formatting:** Corrected structural and formatting errors across numeric and text data fields.
*   **Null Value Management:** Handled missing data entries and blanks to preserve calculation accuracy.
*   **Text Standardisation:** Grouped fragmented strings into standardized categories (e.g., job titles, countries).
